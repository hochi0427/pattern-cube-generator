## 🎯 Learning Goals

Pattern Cube Game supports the development of:

- Spatial visualization
- Shape and pattern recognition
- Mental rotation
- Visual observation
- Short-term memory
- Problem-solving

Instead of learning these concepts only through a screen, children can physically **turn, test, rearrange, and compare** cubes while solving each challenge.

## 🎲 Game Modes

The game can be used in three different ways:

### ⚡ Speed
Observe the pattern and recreate it as quickly as possible.

### 🎲 Random
Work with unexpected cube patterns and adapt your solution.

### 🧠 Memory
Observe the pattern, hide it, and reconstruct it from memory.

## 🧩 Puzzle Generator

The web-based generator creates challenges using multiple views of a cube arrangement:

- **Front View**
- **Side View**
- **Top View**

Players use these visual clues to reconstruct the arrangement with their physical Pattern Cubes.

The number of cubes can be adjusted to create different levels of difficulty.
